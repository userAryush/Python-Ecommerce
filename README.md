# Simple E-commerce CLI Application
The program uses login|register concept as well. At the time of registering you have to specify if you're a seller or a customer then the program will show the options according to it.

## Features

- **User Registration & Login**
  - Register as a seller or buyer.
  - Secure login with username and password.

- **Seller Functions**
  - Add products with name, description, and price.
  - View their own listed products.

- **Buyer Functions**
  - View all available products.
  - Purchase products with quantity input.
  - View purchase bills.

## Data Storage

- User credentials and roles saved in `login.txt`.
- Product information saved in `product.txt`.
- Purchase bills saved in `bill.txt`.
- Data stored in JSON format separated by `|` in text files.
